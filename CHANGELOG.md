## Unreleased (post-v73)

### Fixed — `scripts/install_action_prefix.sh` (review of 4d39b88)

- **Python fallback number fidelity (important).** Numbers are carried as their original token, so `1e400`, `1e-400`, `1.0000000000000000001`, `1.5e3`, big integers and `-0.0` round-trip textually (before: `Infinity`, `0.0`, `1.0`, `1500.0` written back, rc 0). `NaN`/`Infinity` are refused (`parse_constant`), the output is dumped with `allow_nan=False`, re-parsed strictly and compared with the in-memory result before the rename. A UTF-8 BOM is now REFUSED on BOTH paths (jq used to accept it); the jq path also REFUSES `NaN`/`Infinity` (jq turns them into `null` / `1.797e308`; checked with jq 1.8.1 only, other jq versions UNCONFIRMED). The jq path still normalises number spelling itself (for example `1.5e3` becomes `1500`); the textual guarantee is for the python path.
- **`.bak` order and policy (minor).** Validation and merge happen first into a temp file; a refused run writes nothing, so it never creates or clobbers `.bak`. The `.bak` is ORIGINAL-PRESERVING: created once from the pre-install file, never overwritten by later runs (delete it by hand to refresh; an existing `.bak` of any content is kept).
- **Temp-file cleanup (minor).** Own temp files (`.settings.new.*`, `.settings.bak.*`, `.settings.seed.*`) are removed on EXIT, TERM (rc 143) and INT (rc 130); a signal is handled after the running `jq`/`python3` child finishes; `kill -9` cannot be handled and may leave them behind.
- **Hook command quoting (minor, pre-existing).** A hook command containing anything outside `A-Za-z0-9_@%+=:,./-` (a space or quote in the path) is single-quoted; safe paths stay unquoted so existing installs still match (idempotent). Before, a constitution path with a space made `sh -c` fail with rc 127.
- **Very deep nesting (nit).** Both paths now print a `REFUSED` message (python no longer raises a traceback; the jq merge failure message now says `REFUSED`). Documented: a read-only (0444) `settings.json` is still rewritten (rename needs only the directory) and keeps its mode.
- Left as is: the `$settings.tmp` containment check is unused for writes (we use `mktemp`) but is covered by existing tests (M1, H1), so it stays as a harmless guard.
- Tests: `tests/constitution_cmd/test_install_cli_agent_plugins_ownership.sh` gains the `cases_f` set (number fidelity, NaN/Infinity/BOM, `.bak` order and original-preserving, 0444, deep nesting, TERM/INT cleanup, spaced and quoted path) and mutants MV, BAK, BAKORIG, BAKORDER, TRAP, QUOTE, PYNUM, PYNAN, BOM, JQNAN killed by it.
