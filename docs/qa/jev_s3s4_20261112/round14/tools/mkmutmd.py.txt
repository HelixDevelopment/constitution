# A line written by the mutrun.sh rule before its timeout fix (round 14) reads "KILLED-by <suite> rc=124 (no FAIL line)"
# for a run cut by runsuite's timeout; by the fixed rule (tools/test_mutrun.sh.txt) that is NO-RESULT, never a kill.

                 "reclassified by the fixed rule: a run cut by the clock decided nothing)" % (t.group(1), t.group(2), r))
