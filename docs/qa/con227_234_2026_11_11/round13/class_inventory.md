# Class inventory of the network-spawn gate, round 13

Generated by `make_class_inventory.py` (beside this file, run from the repository root) from
`tests/release/netgate_controls.jsonl`. Each class is a way a release script could start a program outside
`rc_net`; every member is a control needle that part 2c of `tests/release/test_channel_census.sh` runs through
`channel_census.py netgate --pin tests/release/netgate_pin.tsv --analyser-only` with an empty PATH. The generator
exits 1 when a control has no class or two, so the inventory and the controls cannot drift apart.

A class lists the members found so far and the rule that refuses them. The analyser is a positive grammar, so a
member not yet found is refused when it falls outside that grammar; this inventory is not a proof that bash has
no other member (the round-12 inventory said "in every form" and "every context"; the round-12 review, F3,
showed members it missed). The byte pin is what makes any unreviewed change to a release script a finding.

Totals: 14 classes, 262 controls that must be a finding, 12 negative controls, 274 controls in all.
