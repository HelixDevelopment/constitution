## Recorded equivalent: PN13

PN13 replaces the check in `pin_regen` for a written name of `DANGER_NAMES` (other than `IFS`) by `if False:`. The
analyser reports every such write as a finding before `pin_regen` reaches that check, and `pin_regen` refuses on any
finding, so the check cannot change the result. The probe `tools/pn13_probe.py` writes one fixture per dangerous name
and runs `pin-regen` with the gate and with the mutant, with an empty PATH; the mutant is equivalent when every pair is
the same `REFUSED` line with rc 1 and no table is written. Result: `pn13_probe.txt`.

## NR8 and the control O70

In the first targeted pre-run NR8 (every long option of sort allowed) was not killed: each control that carries
`--compress-program` also carries an argument that is not a long option (a short option or an operand), which the
mutant still refuses, so it changed no verdict. The fixture `O70_sort_long_option_alone` (`sort --compress-program=git`,
no other argument) was added as a control. The mutant is not equivalent: with it, the gate passes O70 and
`O71_sort_long_options_spill` (only long options) and bash runs the program (`oracle/nr8.cases_r13d.txt`: O70 leak=1,
O71 leak=94).

## AN34, AN37 and the controls O72, O73

The first targeted pre-run (`mutants_targeted_r13_first.tsv`, 100 mutants, on the tree before the last edits;
AN40-AN42 and PN19 were added to the spec after it started) did
not kill three mutants: NR8 (above), AN34 and AN37. Neither of the two is equivalent; each lacked a control that
tells its rule apart, and each got one:

- AN34 drops the `GCONV_` prefix from `is_danger`. Its control O59 writes `GCONV_PATH`, which is also on
  `DANGER_NAMES`, so the verdict and the message were the same with the mutant. `O72_GCONV_prefix_other` writes
  `GCONV_ZZ` (a `GCONV_` name that is not on `DANGER_NAMES`) and expects the dangerous-write finding.
- AN37 stops reading the body of an unquoted here-document. Every here-document is refused (`the redirection
  operator <<`), so the exit status does not change; what the mutant loses is the finding for the command
  substitution in the body (what the refused text would run). `O73_heredoc_body_read` expects that finding
  (`network command outside rc_net: O73_heredoc_body_read.sh:4 git (via -)`), not the refusal.
