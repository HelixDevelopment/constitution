# Class inventory of the network-spawn gate, round 12

Generated by `make_class_inventory.py` (beside this file, run from the repository root) from
`tests/release/netgate_controls.jsonl`. Each class is a way a release script could start a program; every
member is a control needle that part 2c of `tests/release/test_channel_census.sh` runs through
`channel_census.py netgate` with an empty PATH (no lookup on the host). The generator exits 1 when a control
has no class or two classes, so the inventory and the controls cannot drift apart.

Totals: 9 classes, 127 controls that must be a finding, 11 negative controls, 138 controls in all.

*Correction (2026-11-13, round 13, F3 of the round-12 review):* the round-12 gate was not default-deny. Its parser read constructs it did not model without an error (here-document line joining, here-documents across `$(`, process substitution inside `[[ ]]`), and its rules for builtins, local programs and state were deny-lists: 32 reviewer fixtures in K2, K3, K4, K6 and K7 started a network program and passed it, and 8 of the reviewer's 11 narrowing mutants survived every suite (the round-12 review, F1 and F2). The message `unclassified command (default deny)` meant only that a command name outside the closed name lists is a finding. Round 13 replaces the gate with a byte pin of the reviewed scripts and a positive-shape analyser (`../round13/README.md`); this file is kept as it was, with this note. The rules of K2 ("visits every command of every context"; "constructs it does not model are parse errors") and K6 ("a finding in every form"; "`SUBST_RE` is refused in every arithmetic context") are not true of the round-12 gate: the reviewer's fixtures in those classes passed it. The round-13 inventory (`../round13/class_inventory.md`) lists every member found so far and states the rule without "every".
