## The new content lint

`scripts/workable-items/intake_lint.py` (read-only, `python3 -I`). Codes: XREF-DANGLING, XREF-LABEL,
FOREIGN-STALE, STATE-PROSE (prose and hand-written `**Reproduction:**` / `**Investigation:**`
lines), SECTIONS, BODY-SYNC, SECRET (pattern name only), EPHEMERAL (per line), SHARED-PATH,
DUP-CHECK, DUP-SAME-OPEN, PATH-MISSING. Exits 0 / 1 / 2 usage / 3 BLIND. Built-in control needles
run on every call: golden-good texts (with a declared foreign id, an existing evidence path, a
noted ephemeral name, a structured state line, a correct duplicate-of row) must be silent and every
golden-bad text must fire, or the result is BLIND. Guide: `docs/guides/intake_lint_guide.md`.
