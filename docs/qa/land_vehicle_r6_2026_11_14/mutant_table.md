## Labels (R5-H)

* **KILLED**: the observable outcome differs from the unmutated lander: exit status, what
  landed, what ran, or what was printed (a leaked token).
* **EVIDENCE-ONLY**: the same exit status and refs, but a recorded evidence file states
  something false; a test that reads the evidence fails.
* **EQUIVALENT-OUTCOME**: some test's message regex fails, but the outcome (refused,
  nothing landed, same exit status) is the same as the unmutated lander, because another,
  overlapping guard refuses first. Such a mutant does not prove that its own guard is
  load-bearing.
* **SURVIVED**: no test fails.
