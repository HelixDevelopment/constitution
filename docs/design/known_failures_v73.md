## Known limit carried: CLI-agent plugin installer containment

`scripts/install_action_prefix.sh`: the containment checks (settings directory resolves inside the project, hard-link count of `settings.json`, now a warning only) are check-then-write, so they are TOCTOU-narrowed, not closed; a local attacker who can swap a path component between check and use is not defended against (shell has no openat/O_NOFOLLOW chain). Fixed in this release (committed): `scripts/install_action_prefix.sh`, which `install_cli_agent_plugins.sh` runs, replaces `settings.json`, its `.bak` and the temporary file only through fresh `mktemp` inodes renamed into place (never written through); a `settings.json` with more than one hard link (for example after a `cp -al` snapshot) is NOT refused: it is replaced by a new file, the other links keep their old content, and a warning is printed; an existing `settings.json` keeps its mode (read with `stat -L`, so a symlink to a 0644 file yields 0644), a NEW `settings.json` or `.bak` gets the umask-respecting mode (0666 minus umask); invalid JSON in `settings.json` is refused (non-zero, file unchanged) on both the jq and the python3 path; and the generator is run with an ambient `HELIX_ACTION_OUT_ROOT` unset.

Two reclaimers judge the same stale lock; the first renames it away, removes it and creates its own lock; the second, still holding the old snapshot, renames the NEW owner's lock away, sees the signature differ and puts it back. While it is away the owner's `lock_is_mine` re-check fails, so nobody runs and the put-back leaves a lock with a dead owner. RED on the unfixed code: test R1 `calls=0`, lock left behind; the owner logged "no longer this process's (taken over meanwhile)", the late reclaimer "a concurrent locker". Fix: reclaimers in all three lockers of this lock file (the consumer, `scripts/hooks/post-merge`, `scripts/setup.sh`) are serialised by an flock on `<git-dir>/constitution-pending-update.reclaim` and re-take the snapshot under it before the rename (no flock(1): a stale lock is not reclaimed, WARNING, stamp stays). GREEN: R1, R1b, LK-17, LK-17b; paired mutations TL1-TL4 killed. Natural timing (no seam, measured by the independent review of 2026-11-03, 40 runs each): the unfixed hook failed 11 of 40 runs, the fixed hook passed 40 of 40. Whether this race is the cause of the one historical 39/1 run is still UNCONFIRMED (that run's failing assertion was never captured), but the race occurs under natural timing and produces exactly that shape (one m6 assertion FAIL). Round 2 (review finding): the mutex path is opened only when it is absent or a regular non-symlink file, because an open of a FIFO there blocks before `flock -w` (test R2-F1, LK-18, LK-19, each under `timeout`); every locker names the real cause (flock missing, mutex not regular or unopenable, mutex timeout).
