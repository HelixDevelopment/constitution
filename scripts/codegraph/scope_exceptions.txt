# scope_exceptions.txt — narrow, per-EXACT-path exceptions for codegraph_safe_helper.py's
# post-index scope audit (`cmd_scope`, invoked by `codegraph_safe.sh verify`).
#
# Format:  <class> <exact-project-relative-path>   # <justification>
#   - <class> MUST be one of ALLOWED_EXCEPTION_CLASSES in codegraph_safe_helper.py
#     (currently: secret_named, secrets_dir). Any other class is a hard error —
#     credential-CONTENT classes (env_file/keystore/signing_key/service_account,
#     §11.4.10) admit NO exceptions, ever.
#   - <path> MUST be an EXACT project-relative path — never a glob/pattern. A typo
#     simply never matches anything and the underlying SCOPE_CLASS FAIL persists
#     (fail-closed): this file can only narrow an ALREADY-VERIFIED hit, never widen
#     what the baseline patterns themselves catch.
#   - Every entry below was content-inspected (not just name-inspected) before being
#     added, and carries a one-line reason. Adding an entry without that inspection
#     is a §11.4.6 violation (no-guessing) at the security-hygiene layer.
#
# Context (§11.4.201 / §11.4.273): the `secret_named` (segglob:*secret*) and
# `secrets_dir` (dir:secrets) baseline classes in scope_baseline.txt are
# deliberately broad path-substring heuristics — a defense-in-depth net, INDEPENDENT
# of and stricter than the actual CodeGraph indexing exclude config
# (.codegraph/config.json only excludes literal `secrets/**` directories, not any
# path merely containing the substring "secret"). Broad-by-design means broad
# false-positive rate on a large, real-world codebase: this repo ships AOSP/Google
# source that legitimately implements or discusses the CONCEPT of a "shared secret"
# (crypto HAL protocols, a Secret-Manager API schema) or that SCANS FOR secrets
# (this project's own credential-scanning tooling) — none of which is a credential
# leak. Loosening the glob itself was rejected: it would also narrow detection of a
# genuinely new secret-shaped file. A narrow, human/agent-verified, exact-path
# allowlist is the sanctioned pattern this project already uses for the identical
# problem class elsewhere (the pre-commit credential scanner's docs/accesses/
# accounts.* + .env-class allowlist).
#
# Cross-refs: codegraph_safe_helper.py (load_exceptions/cmd_scope),
# constitution/scripts/codegraph/scope_baseline.txt, docs/scripts/codegraph_safe.md,
# constitution §11.4.10 / §11.4.78 / §11.4.201 / §11.4.273.
