### §11.4.251 — Byte-identical-fork prohibition + role-as-data-pack (research-derived, 2026-08-15)

Full anchor per Phase 3 landing brief §11.4.251. When project needs would be met by TWO NEAR-IDENTICAL CODE COPIES differing only in configuration/data/role-specific parameters (prod + staging with hardcoded hostnames; reader + writer with different flag values; web + mobile with different feature flags), copies MUST NOT be maintained as parallel forks.
