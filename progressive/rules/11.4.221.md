### §11.4.221 — Motion discipline: token-bound durations/easings + machine-readable manifest + reduced-motion static fallbacks everywhere (User mandate, 2026-07-22)

**Forensic anchor — proving project (Helix Thready MVP design package, 2026-07-22).** Helix Thready's `design/motion/` package proves the discipline: six hand-authored vector Lottie animations bound to the token motion values, each validated by parse + structural schema check + REAL render (lottie-web under jsdom with animation-progression assertions, plus headless-Chromium light+dark contact sheets) — unverified runtimes (`lottie-compose` / `lottie-ios`) honestly `[OPEN]`-tracked; FIVE static reduced-motion fallback SVGs whose geometry is DERIVED FROM THE LOTTIE KEYFRAMES (the exact poster frame for loopers, the final frame for one-shots); and a machine-readable `motion-manifest.json` v2 naming, per animation, its loop mode, poster frame, segment markers, and `reducedMotionFallback` — with one DELIBERATE `null` (an instant-cut transition) recorded with its reason, never a silent absence.

**The mandate.** All motion in every governed project MUST satisfy: (1) **Token-bound timing** — every duration and easing binds to the §11.4.216 motion tokens (the shared base durations + easing curves); documented choreography MAY extend them, but an animation timed by an ad-hoc literal that bypasses the token layer is a §11.4.221 violation (per §11.4.6 no-invented-values). (2) **Reduced-motion fallback per animation** — every playable animation ships a STATIC fallback derived from its own keyframes (poster frame for looping animations, final frame for one-shots), delivered as an open-format asset; where the correct reduced-motion behavior is intentionally something else (instant cut, no artwork), that is recorded EXPLICITLY in the manifest with its reason — a missing fallback is a gap, a silent missing fallback is a violation. (3) **Machine-readable manifest** — a versioned motion manifest enumerates every animation with its id, loop mode, poster frame, reduced-motion mode, and fallback reference; runtimes consume the MANIFEST, not folklore. (4) **`prefers-reduced-motion` honored everywhere** — every surface (web, library, screens, previews, implementations) gates motion on `prefers-reduced-motion: reduce` with TARGETED component-level gates (never a global `*` kill-switch, per the §11.4.217 review lens), swapping in the manifest-named fallback. (5) **Render-validated, honestly bounded** — no animation is claimed working without a real render in a real runtime (the §11.4.107(10) analyzer discipline applied to motion assets: parse + structure + rendered geometry with progression assertions); runtimes not yet exercised are named `[OPEN]` items, never assumed.

**Honest boundary (§11.4.6).** The manifest + fallbacks prove reduced-motion COVERAGE; they do not prove physical-display fidelity (a pixel A/B of statics against frozen frames on a real display remains its own tracked item), and jsdom/headless renders do not certify mobile runtimes — the boundary is stated, tracked, and never blurred.

Classification: universal (§11.4.17) — the consuming project supplies its animation inventory, motion tokens, manifest path, and runtime list per §11.4.35. Composes §11.4.6 / §11.4.107(10) / §11.4.162 / §11.4.170 / §11.4.216 / §11.4.218 / §11.4.223. Propagation gate `CM-COVENANT-114-221-PROPAGATION` (literal `11.4.221`) + recommended gate `CM-MOTION-TOKEN-BOUND-REDUCED-FALLBACK` (every animation's timing resolves to tokens; the manifest enumerates every playable animation; every manifest entry names a fallback or an explicit recorded null-with-reason; every animation carries its parse/structure/render validation record) + paired §1.1 mutation (add an animation with a literal ad-hoc duration → gate FAILs; drop a fallback reference without a recorded reason → gate FAILs; strip the literal → propagation gate FAILs; gate-code = separate work item).

**Canonical authority:** constitution submodule [`Constitution.md`](Constitution.md) §11.4.221.

Non-compliance is a release blocker regardless of context. No escape hatch — no `--ad-hoc-duration`, `--no-reduced-motion-fallback`, `--global-star-motion-kill`, `--manifest-optional`, `--unrendered-animation-claimed-working` flag exists.
