### §11.4.222 — Design-completion export wave: a design is not done until token codegen, the honest-output raster matrix, both-theme renders, hand-off bundles, and doc twins land (User mandate, 2026-07-22)

**Forensic anchor — proving project (Helix Thready MVP design package, 2026-07-22).** Helix Thready's export capstone proves the wave: an icon/asset raster matrix locked 1:1 to its generator (`generate-raster.sh`), which SELECTS its SVG renderer by PROBE — each candidate (rsvg-convert → inkscape → resvg → headless Chromium → ImageMagick) must pass a real probe render with content verification before it is used, a failing candidate falls through with a note, and if NONE passes the script exits with instructions and writes NOTHING ("No PNGs were written (output is not faked)"); an absent bundler (iconutil for `.icns`) SKIPs with a note — a verified live run produced 83 REAL rasters, every one checked non-blank; 49 screen PNGs (22 screens × light+dark at a confirmed 2× scale, theme forced deterministically, every file verified size-floor + stddev > 0); a 54-page bound design book; and PenPot + Figma hand-off bundles whose impossible/operator-only legs are recorded as DEFERRED with reasons — never faked.

**The mandate.** A design (a design system, a brand, a screen set, or a design change wave) is NOT "done" until its EXPORT WAVE has run and its outputs are verified: (1) **Per-platform token codegen** — the §11.4.216 generated bindings are (re)generated from the canonical token source, or their absence is `[OPEN]`-tracked. (2) **Full icon/asset raster matrix via an honest-output pipeline** — the per-platform pixel/format matrix (every OS surface) is documented, locked 1:1 to a generator script, and produced by a pipeline that (a) PROBE-TESTS every candidate renderer with a real content-verified probe render before trusting it (§11.4.201 — a renderer's presence is not its correctness; an unprobed renderer would silently emit blank/garbage icons), (b) falls through to the next candidate on probe failure, (c) SKIPs-with-note any step whose tool is genuinely absent (§11.4.3 / §11.4.69 honest-skip discipline), and (d) NEVER writes a placeholder, blank, or faked output — every produced raster is verified non-degenerate (size floor + non-blank content check; multi-resolution bundles verified to contain their declared members, per §11.4.38's open-the-artifact discipline). (3) **Both-theme screen renders + bound design book** — every catalogue screen rendered in light AND dark at the declared scale with deterministic theme forcing, each render verified non-blank, and the set bound into the portable design book. (4) **Hand-off bundles** — the open-platform and proprietary-bridge bundles (§11.4.220) built with per-leg HONEST statuses: produced / deferred-operator-only / impossible-with-reason. (5) **Doc twins regenerated** — the design area's §11.4.65 / §11.4.73 export siblings are regenerated so no reader gets a divergent view. A design wave reported complete without its export wave — or with any faked/unverified export output — is a §11.4 PASS-bluff at the design-delivery layer.

**Honest boundary (§11.4.6).** The export wave proves the design's ARTIFACTS exist, are real, and are non-degenerate; it does not prove visual correctness on physical displays (§11.4.170 / §11.4.190 / §11.4.185 own that), and a wave rendered before later additions is honestly stamped with its coverage boundary — regeneration lands as a tracked downstream pass, never claimed retroactively.

Classification: universal (§11.4.17) — the consuming project supplies its raster matrix, generator, renderer candidates, book builder, and bundle targets per §11.4.35. Composes §11.4.3 / §11.4.6 / §11.4.38 / §11.4.65 / §11.4.69 / §11.4.73 / §11.4.201 / §11.4.216 / §11.4.219 / §11.4.220. Propagation gate `CM-COVENANT-114-222-PROPAGATION` (literal `11.4.222`) + recommended gate `CM-DESIGN-EXPORT-WAVE-COMPLETE` (the raster generator probe-tests renderers and content-verifies outputs; the matrix doc and generator agree 1:1; every screen has both-theme verified renders or a tracked gap; every bundle leg carries an honest status; the doc twins are in sync) + paired §1.1 mutation (make a renderer skip its probe, or write a placeholder PNG on renderer absence → gate FAILs; report the wave complete with a stale doc twin → gate FAILs; strip the literal → propagation gate FAILs; gate-code = separate work item).
