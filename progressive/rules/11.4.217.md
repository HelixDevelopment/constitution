### §11.4.217 — OpenDesign brand contract: every UI-shipping product carries a 9-section DESIGN.md + tokens.css twin with disjoint color roles, AA-pinned accents, and a locked attribution footer (User mandate, 2026-07-22)

**Forensic anchor — proving project (Helix Thready MVP design package, 2026-07-22).** Helix Thready ships `design/opendesign/DESIGN.md` in the OpenDesign 9-section brand-contract schema — VERIFIED against the tool's own source per §11.4.99 (spec, `design-systems/README.md`, the contributor authoring guide, and a measured 150-file corpus: two coexisting heading families, both parsed by number prefix only) — plus its machine-readable twin `tokens.css` per the OpenDesign token schema, and an honest `TOOLING.md` capability check. The contract encodes three DISJOINT color roles (brand decorative, accent interactive, semantic state), the closed white-label override set the three shipped sibling themes prove works, and the locked attribution footer.

**The mandate.** Every product governed by this Constitution that ships user-facing interfaces MUST carry an OpenDesign brand contract under its design area (`design/opendesign/` or the project's declared equivalent per §11.4.35), consisting of: (1) **`DESIGN.md` in the verified 9-section schema** — H1 product title with the `> Category:` blockquote IMMEDIATELY after the H1 (the picker parses the line immediately after the H1), nine numbered sections (the parser matches the number prefix, not the heading text), a "Font labels for catalog extraction" block (`Display:` / `Body:` / `Mono:` lines) in the typography section, real hex codes, CSS variables wrapped in `:root {}` (never bare) with dark tokens via the `[data-theme="dark"]` override pattern, real component CSS with `prefers-reduced-motion` targeting specific elements (never a global `*`), and `:focus-visible` on every interactive component — the tool's own blocking review lens, satisfied in-file. Format claims are verified against the tool's CURRENT source per §11.4.99, never assumed from memory. (2) **The `tokens.css` machine-readable twin** — the §11.4.216 canonical token file (or a compiled view of it), following the tool's token schema; prose and tokens never diverge. (3) **Disjoint color roles by contract** — brand is DECORATIVE only (never body text; the Thready brand base measures 1.47:1 on white — decorative by physics, not by preference), accent is INTERACTIVE and AA-PINNED (each accent/on-accent pair carries a measured ≥ 4.5:1 ratio against its paired background, both modes), semantic (success / warn / danger) is STATE and is NEVER overridden by a brand — a brand color can never mask an error signal. (4) **White-label closed override set, server-validated** — per-account branding may swap decorative brand tokens, the accent pair, logo, and slogan; accent overrides are SERVER-VALIDATED to WCAG AA ≥ 4.5:1 or REJECTED (the rejection carries the measured ratio + an AA-passing suggestion — instructive, never bare); structural tokens, neutral surfaces, and semantic tokens are NOT account-overridable (advanced neutral overrides gate behind a full AA re-validation). (5) **Locked attribution footer** — the organization's attribution footer ships on every surface and is NEVER removed, even fully white-labeled.

**Honest boundary (§11.4.6).** The contract governs DEFINITION and roles; it does not prove rendered correctness (§11.4.170 / §11.4.190) nor replace §11.4.162's token-system, test-coverage, and extend-don't-reimplement obligations — this anchor pins the contract ARTIFACT §11.4.162 consumes. Schema-version drift between the local tool checkout and the doc is recorded as fact and re-verified at integration, never papered over.

Classification: universal (§11.4.17) — the consuming project supplies its brand values, category line, white-label storage/API bindings, and attribution string per §11.4.35. Composes §11.4.6 / §11.4.99 / §11.4.162 / §11.4.190 / §11.4.216 / §11.4.220 / §11.4.223. Propagation gate `CM-COVENANT-114-217-PROPAGATION` (literal `11.4.217`) + recommended gate `CM-OPENDESIGN-BRAND-CONTRACT` (DESIGN.md present with the 9 numbered sections + category blockquote + font-labels block + `:root {}` + `[data-theme="dark"]` + targeted reduced-motion; tokens.css twin present and consistent; accent pairs carry measured ratios; the attribution footer token/lockup is present and not account-overridable) + paired §1.1 mutation (drop the font-labels block, or let a brand token override `--danger`, or mark the footer overridable → gate FAILs; strip the literal → propagation gate FAILs; gate-code = separate work item).
